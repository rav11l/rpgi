# Панель RPGI для digitaleconomylab.ru

`rpgi-embed.html` — содержимое HTML-блока (T123) на главной странице сайта. Блок:

- читает ряды прямо из этого репозитория (`raw.githubusercontent.com`, кеш около 5 минут),
  поэтому после слияния pull request от еженедельного workflow графики на сайте обновляются сами;
- если GitHub недоступен, рисует встроенный снимок данных и помечает это в строке статуса;
- сам встаёт под карточкой RPGI в разделе «Инструменты» (ищет карточку по тегу `RPGI`)
  и переключает язык вместе с сайтом (атрибут `lang` у `<html>`).

Код блока меняется здесь, затем содержимое файла целиком вставляется в блок в Tilda.
Встроенный снимок данных обновлять не обязательно: он нужен только на случай недоступности GitHub.
