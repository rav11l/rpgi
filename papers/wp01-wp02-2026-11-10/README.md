# WP-2026-01 and WP-2026-02

Original manuscript date: 11 September 2026. Web revision: 10 November 2026.

Published pages: https://digitaleconomylab.ru/wp-2026-01 and https://digitaleconomylab.ru/wp-2026-02 (Russian and English).

The ZIP contains the frozen source workbooks, original land-audit log and matrix, revised matrix and verification program. Extract it and run `python verify_numbers.py research-sources` with Python 3, numpy and openpyxl. Verification results are written next to the program. No network access is needed. The WP-04 model was cross-checked against its output rather than re-estimated.

The revised land matrix recodes September observations; it is not a new November census of city records. Three Saint Petersburg cells were corrected. Original evidence is preserved.
