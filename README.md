# RPGI — Regional Price Gap Indicator, v0.2.0

[![DOI](https://zenodo.org/badge/DOI/10.5281/zenodo.22693769.svg)](https://doi.org/10.5281/zenodo.22693769)

Открытый индикатор разрыва цен между первичным и вторичным рынками жилья по центрам
субъектов Российской Федерации и доли ипотечных выдач, уходящей на договоры долевого
участия, по регионам.

**Зачем.** Разрывом цен первички и вторички публично измеряют состояние рынка жилья: по нему
спорят о пузыре, сравнивают регионы, обсуждают надбавки к капиталу банков. При этом сама
величина считается по средним ценам и композиционно зависима. По данным Казани расширение
разрыва в 2024–2025 годах объясняется преимущественно тем, какие квартиры дошли до сделки,
а не подорожанием сопоставимого метра. Индикатор считает разрыв воспроизводимо, публикует
рядом разложение на цену и состав и связывает разрыв с долей ипотечных денег, уходящих
на новостройки.

## Что считается

| Метрика | Определение | Разрез | Файл |
|---|---|---|---|
| `gap_pct` | (средняя цена первичного рынка − вторичного) / вторичный × 100. Графа «Все типы квартир», среднее I и II кварталов | центр субъекта, год | `data/rpgi_v0.1.0.csv` |
| `median_centres_pct`, `rank`, `gap_to_median` | медиана по кругу центров, место центра, отношение к медиане | год | `data/rpgi_v0.1.0.csv` |
| `ddu_share_pct` | объём ИЖК под ДДУ / объём ИЖК, по объёму в рублях | регион, месяц | `data/cbr_rf_rt_ddu_share_2019_2026.csv` |
| `corr_levels`, `corr_first_diff` | связь разрыва с долей в уровнях и первых разностях, в двух окнах | регион | `data/rpgi_v0.1.0_correlations.csv` |
| срез февраля 2026 | доли января и февраля и изменение в п. п. по 83 регионам | регион | `data/cbr_ddu_share_regions_2026_02.csv` |
| доля по числу договоров | количество ИЖК под ДДУ / количество ИЖК (02_10 и 02_15) | регион, месяц | считает `code/counts_check.py` |
| ставки | средневзвешенные ставки по всем ИЖК и по ИЖК под ДДУ; ставка по прочим разворачивается из тождества | Татарстан, месяц | `data/cbr_rates_rt_2021_2026.csv` |

## Источники

- Росстат, «Средние цены на первичном / вторичном рынке жилья по субъектам и центрам
  субъектов Российской Федерации», лист «по центру субъекта РФ». Двенадцать книг
  в `data/sources/rosstat/`, sha256 — в `hashes_rosstat.json`.
- Банк России: 02_11 и 02_16 (объёмы ИЖК и ИЖК под ДДУ), 02_10 и 02_15 (количества
  договоров), 02_13 и 02_17 (средневзвешенные ставки), помесячно с января 2019 года.
  Файлы в `data/sources/cbr/`, sha256 — в `hashes_cbr.json`.

Строки рядов названы по субъекту, значения относятся к его административному центру:
так устроен исходный лист Росстата.

## Воспроизведение

```
python code/rosstat_parse.py    # книги Росстата → data/rosstat_centres_gap_2021_2026.csv
python code/cbr_ddu_share.py    # таблицы ЦБ → доли по РФ, РТ и по 83 регионам
python code/cbr_rates.py        # 02_13 и 02_17 → data/cbr_rates_rt_2021_2026.csv
python code/rpgi.py             # метрики, медианы, места, корреляции

python code/within_region.py    # внутрирегиональные корреляции в уровнях
python code/fe_panel.py         # панель с двусторонними фиксированными эффектами
python code/counts_check.py     # то же на долях по числу договоров
python code/rates_check.py      # связь разрыва с разницей ставок
python code/figs_article.py     # три рисунка в figs/ (нужен matplotlib)
```

Зависимости: Python 3.9+, `openpyxl`; для `figs_article.py` дополнительно `matplotlib`.
Ничего больше. Все пути внутри скриптов рассчитываются от их собственного
расположения, так что депозит работает из любой папки.

Столбец «Все типы квартир» определяется по тексту шапки, а не по номеру: у первичного и
вторичного рынков разное число подстолбцов качества, и подстановка соседнего столбца даёт
систематическое занижение разрыва. На этом строилась ошибка первой версии ряда — см.
`CHANGELOG.md`, там она описана полностью, включая величину смещения по годам.

## Границы применимости

1. **Сырой разрыв композиционно зависим.** По Татарстану сцепленный индекс цен показывает,
   что премия за новостройку не росла с 2023 года, а в 2026 году отрицательна (−5,3 % и
   −3,0 % по кварталам), тогда как сырой разрыв в те же годы 46–51 % и 30 %. Для калибровки
   надбавок сырой разрыв без очистки непригоден; индикатор публикует его именно вместе
   с этим сопоставлением.
2. **Шесть годовых наблюдений на регион.** Корреляции читаются как совпадение режимов,
   а не как оценённый эффект. С версии 0.2.0 связь проверена на панели: в уровнях она
   видна почти везде (медиана внутрирегиональной корреляции +0,60, положительна у 86 %
   из 71 региона, Татарстан +0,89 — четвёртое место), но это общий фон. В спецификации
   с двусторонними фиксированными эффектами (год и регион, 351 наблюдение, 73 региона)
   не остаётся ничего: r = −0,014, наклон −0,039 п. п. разрыва на 1 п. п. доли, t ≈ −0,26.
   Это точный ноль с узким интервалом, а не «не нашли». Считают `code/within_region.py`
   и `code/fe_panel.py`. Ноль относится к **региональному дозовому отклику**: тайминг
   программы общий для всех регионов и поглощается год-эффектами, поэтому эффект
   общенациональной политики этой спецификацией не идентифицируется ни в какую сторону.
3. **Окна двух рядов различаются.** Ценовой ряд — I и II кварталы; доля выдач по умолчанию
   считается за весь доступный год (2026 год неполный: январь–июль). В том же окне, что
   и цены, связь слабее: 0,80 против 0,89 в уровнях и 0,57 против 0,66 в разностях.
   Обе величины считаются `code/rpgi.py` и лежат в `data/rpgi_v0.1.0_correlations.csv`.
4. **Доля считается по объёму в рублях** и потому частично движется вместе со средним чеком
   новостройки. С версии 0.2.0 есть пересчёт по количеству договоров (`code/counts_check.py`,
   таблицы 02_10 и 02_15): по Татарстану связь слабеет, но сохраняет знак и порядок —
   0,78 против 0,89 в уровнях и 0,46 против 0,66 в разностях. Механическая составляющая
   реальна и составляет около 0,11 из 0,89, но связь не создаёт. На панели результат
   не меняется: объединённая корреляция разностей −0,019, двусторонние фиксированные
   эффекты −0,036 при t ≈ −0,68.
5. **ДДУ не тождественно льготной программе.**
6. **Круг центров меняется по годам** (72–77): включаются те, где опубликованы оба рынка
   за оба квартала.
7. **Ценовой ряд — по городу, ряд выдач — по региону.**
8. **Связь разрыва с разницей ставок** воспроизводится с версии 0.2.0. База сравнения —
   ставка по **прочим** ИЖК, развёрнутая из тождества `r_все·V_все = r_ДДУ·V_ДДУ + r_проч·V_проч`,
   а не средняя ставка по всем ИЖК. `corr(разрыв, r_проч − r_ДДУ)` = +0,045 в уровнях
   (опубликованное значение 0,04) и −0,152 в первых разностях; в окне I–II кварталов
   −0,056 и −0,378. Сравнение со **средней** ставкой даёт +0,513 и является артефактом:
   `r_ДДУ − r_все ≡ (1 − s)·(r_ДДУ − r_проч)`, то есть пересказывает долю выдач `s`,
   а не ставки. Расчёт — `rates_check.py`, ряд ставок — `code/cbr_rates.py`.

## Известные значения

Центр субъекта — Казань:

| Год | Разрыв, % | Медиана центров, % | Место | Отношение к медиане |
|---|---|---|---|---|
| 2021 | 8,32 | 4,91 | 25 / 72 | 1,69 |
| 2022 | 12,12 | 8,02 | 27 / 75 | 1,51 |
| 2023 | 21,50 | 11,16 | 13 / 75 | 1,93 |
| 2024 | 46,18 | 18,88 | 3 / 77 | 2,45 |
| 2025 | 50,94 | 17,84 | 3 / 76 | 2,86 |
| 2026 | 30,00 | 21,33 | 17 / 76 | 1,41 |

Корреляция разрыва с долей выдач под ДДУ по Татарстану: +0,889 в уровнях и +0,661
в первых разностях (доля за год); +0,798 и +0,569 в окне I–II кварталов.

Февраль 2026 года: доля выдач под ДДУ упала одновременно в 82 регионах из 83. По России
61,5 → 43,9 %, медианный регион −17,8 п. п., разброс от −30,0 до +12,5 п. п.; единственный
рост — Республика Адыгея (73,9 → 86,4 %). Татарстан −20,3 п. п., 28-е место по глубине
падения. По числу договоров слом глубже: по России 52,8 → 32,9 %, по Татарстану
53,1 → 29,6 %.
