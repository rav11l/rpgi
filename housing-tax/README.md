# housing-tax — расчёты к WP-2026-07

Каталог воспроизводит числа working paper **WP-2026-07 «Налог на непроданные квартиры в Татарстане»**
(Р. Ахтямов, Digital Economy Lab, версия 1.2, 21.10.2026; https://digitaleconomylab.ru/wp-2026-07).

## Состав

| Файл | Что это |
|---|---|
| `calc.py` | Весь расчёт: остаток непроданного жилья в сданных домах Казани по ЕИСЖС, нагрузка на метр и на типовой проект, сценарии поступлений по РТ, покрытие проектного долга эскроу. Блок `v1.1` учитывает шестимесячный срок на регистрацию права застройщика. |
| `calc_results.json` | Результат `calc.py`. Ключи `v11_rt` и `v11_project` — основные оценки работы (версии 1.1 и 1.2); `rt` и `project` — оценки версии 1.0, налог с момента ввода. |
| `sources/proekt_zakona_RT_nalog_na_imushchestvo_2026-10-12.docx` | Текст проекта закона РТ «О внесении изменений в Закон РТ „О налоге на имущество организаций“», размещённый Минфином РТ 12.10.2026. |
| `hashes_sources.json` | sha256 исходных файлов, включая входные файлы из `escrow/`. |
| `WP-2026-07/WP-2026-07.pdf` | Текст работы, версия 1.2. |

## Входные данные

Те же файлы, что в WP-2026-05, из каталога `escrow/` этого репозитория (хеши совпадают):

- `escrow/sources/eisgs/eisgs_kazan_objects.csv` — выгрузка ЕИСЖС (наш.дом.рф) по объектам Казани на 26.09.2026;
- `escrow/cbr_pf_regions.csv` — помесячная информация Банка России о проектном финансировании по субъектам РФ.

Параметры, не выводимые из файлов, заданы в начале `calc.py` явно: средняя кадастровая стоимость квартир Казани 122 тыс. руб./м²; средняя цена первичного рынка 234 тыс. руб./м²; ввод коммерческих МКД в РТ около 1,0 млн м² в год; модельный проект 50 тыс. м² из доклада. Источники — в тексте работы.

## Запуск

```
python housing-tax/calc.py
```

Нужны pandas и numpy. Скрипт перезаписывает `calc_results.json`; результат совпадает с файлом в репозитории.

## Границы

Оценки сценарные. Официальной статистики остатка непроданного жилья в сданных домах нет; доля непроданного (около 22 %) измерена по 187 сданным в 2023–2026 годах объектам Казани с опубликованной распроданностью и перенесена на РТ. Срок распродажи остатка и доля квартир, проданных до регистрации права, — допущения, а не измерения.
